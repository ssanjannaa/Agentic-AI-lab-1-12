# Common Cybersecurity Terminology

## Essential Terms and Definitions
- **CIA Triad:** The foundational security framework standing for **Confidentiality** (preserving authorized access limits), **Integrity** (safeguarding data accuracy and completeness), and **Availability** (ensuring timely, reliable access to resources).
- **CVE (Common Vulnerabilities and Exposures):** A dictionary of publicly disclosed cybersecurity vulnerabilities, identified by unique IDs (e.g., CVE-2024-12345).
- **Zero-Day Vulnerability:** A security flaw in software or hardware that is unknown to the vendor and for which no official patch or fix currently exists.
- **Threat Actor:** An individual or group that intentionally executes malicious cyber activities against computer systems or networks.
- **Defense-in-Depth:** A security strategy incorporating multiple redundant security layers (firewalls, EDR, access controls, encryption) so that if one security layer fails, subsequent layers continue to protect assets.
- **Principle of Least Privilege (PoLP):** Granting users and processes only the minimum access rights required to perform their explicit job functions.
