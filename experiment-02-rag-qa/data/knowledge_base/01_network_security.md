# Network Security Fundamentals

## Overview
Network security consists of policies, processes, and practices adopted to prevent, detect, and monitor unauthorized access, misuse, modification, or denial of a computer network and network-accessible resources. Modern enterprise network security relies on defense-in-depth, layering multiple security controls across network boundaries.

## Key Components of Network Security
1. **Network Segmentation:** Dividing a larger network into smaller, isolated subnets or VLANs to limit lateral movement by malicious actors in case of a breach.
2. **Virtual Private Networks (VPNs):** Encrypted communication tunnels that secure data in transit between remote users and internal enterprise networks over public internet channels using protocols like IPsec or OpenVPN.
3. **Transport Layer Security (TLS):** Cryptographic protocols designed to provide communications security over a computer network, establishing encrypted links between web servers and web browsers (HTTPS).
4. **Intrusion Detection Systems (IDS):** Monitoring devices that inspect network traffic for suspicious activity or known threat signatures and issue alerts to security analysts.

## Network Security Best Practices
- Enforce strict perimeter filtering using stateful firewalls.
- Implement network access control (NAC) to authenticate devices before granting network access.
- Conduct continuous network traffic monitoring and packet analysis to detect anomalous outbound data exfiltration.
