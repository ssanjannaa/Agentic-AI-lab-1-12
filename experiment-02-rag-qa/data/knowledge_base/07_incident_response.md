# Incident Response Phases

## Overview of Incident Response
Incident Response (IR) is a structured methodology followed by cybersecurity organizations to handle, manage, and mitigate security breaches, unauthorized intrusions, or cyber attacks effectively to minimize operational damage.

## The 6 Phases of Incident Response (NIST / SANS Framework)
1. **Preparation:** Establishing incident response plans, training personnel, configuring logging tools, and creating communication workflows before security incidents occur.
2. **Identification (Detection):** Analyzing security alerts, SIEM logs, and system anomalies to detect, confirm, and scope active security incidents.
3. **Containment:** Taking immediate tactical steps to prevent the spread of a breach (e.g., isolating compromised subnets, revoking credentials, disabling affected endpoints).
4. **Eradication:** Removing the root cause of the incident from infected environments (e.g., deleting malware binaries, patching vulnerabilities, closing unauthorized backdoors).
5. **Recovery:** Restoring affected systems to clean operational production after thorough validation and testing.
6. **Lessons Learned:** Post-incident review to analyze attack root causes, document timelines, update security controls, and improve response procedures.
